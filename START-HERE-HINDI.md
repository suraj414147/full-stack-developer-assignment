# Assignment start guide (Hindi)

## React restaurant app chalane ke liye

1. ZIP extract karein.
2. `full-stack-developer-assignment` folder VS Code mein open karein.
3. Terminal mein is folder ke andar ye commands chalayein:

```powershell
npm install
npm run dev
```

4. Browser mein `http://localhost:5173` open karein.

Frontend Fastor staging API ke Register, Login aur Restaurants endpoints use karta hai. Real OTP/SMS aur live restaurant response staging API ki availability, credentials/eligibility aur network/CORS settings par depend karte hain. API fail hone par app demo restaurant cards dikha sakti hai.

## Important
- OTP screenshot mein `123456` default test value ke roop mein dikhaya gaya tha; real staging API par har number ke liye kaam karne ki guarantee nahi hai.
- `npm install` pehli baar internet connection maangta hai.
- API se live login verify hue bina submission ko fully live-tested na samjhein.

## Build check
```powershell
npm run build
```
